# Simple MP3 — iOS App Store assets

Real Simulator captures of the iOS app (demo-seeded library), plus marketing frames sized for App Store Connect.

## iPhone dimensions (App Store Connect)

Upload portrait screenshots that match **one** of these slots:

| Size | Display | Folder |
|------|---------|--------|
| **1284 × 2778** | 6.7" (primary) | `screenshots/iphone-clean/` and `screenshots/iphone/` |
| **1242 × 2688** | 6.5" (alternate) | `screenshots/iphone-6.5-clean/` and `screenshots/iphone-6.5/` |

Also accepted (landscape, not generated by default): `2688 × 1242`, `2778 × 1284`.

> Do **not** use 1320×2868 — App Store Connect rejects that for the 6.5"/6.7" slots.

## What to upload

**Recommended (looks exactly like the app):**

- `screenshots/iphone-clean/*.png` → **1284 × 2778**
- If Connect asks for 6.5" only: `screenshots/iphone-6.5-clean/*.png` → **1242 × 2688**
- `screenshots/ipad-clean/*.png` → iPad 13"
- `graphics/AppIcon-1024.png`

Optional marketing chrome: `screenshots/iphone/` and `screenshots/ipad/`.

## Regenerate

From the repo root (preferred):

```bash
make screenshots-ios              # capture + render (full pipeline)
make screenshots-ios-capture      # Simulator → raw PNGs only
make screenshots-ios-render       # marketing frames + 1284×2778 / 1242×2688 only
make screenshots-android          # Play Store HTML → PNGs
make screenshots                  # Android + iOS
```

Or run the scripts directly:

```bash
cd store-listing/ios
./capture-screenshots.sh   # Simulator → raw PNGs
./render.sh                # marketing + resize to 1284×2778 and 1242×2688
```

**Requirements:** Xcode + Simulator (capture), Google Chrome (render). Free a few GB of disk before capture.

Demo launch args: `-ScreenshotDemo -ScreenshotScene home` (skips Media Library permission).
